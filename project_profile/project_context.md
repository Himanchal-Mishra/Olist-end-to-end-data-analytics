# Olist E-Commerce Analytics Project

## Project Overview

This project analyzes the Olist Brazilian E-Commerce dataset to build an end-to-end analytics solution covering data profiling, data modeling, data validation, SQL analytics, and business intelligence reporting.

The objective is to transform raw transactional data into a structured analytical model that supports business decision-making across customer, product, seller, logistics, payment, and marketing domains.

---

## Business Context

Olist is a Brazilian e-commerce marketplace that connects customers with multiple sellers across different product categories.

The platform generates transactional data across the entire customer journey, including purchases, payments, deliveries, reviews, products, sellers, and customer information. Additional marketing datasets provide visibility into seller acquisition and lead conversion processes.

To support data-driven decision-making, stakeholders require a centralized analytical model capable of tracking marketplace performance, customer behavior, operational efficiency, seller performance, and marketing effectiveness.

---

## Project Objectives

The primary objectives of this project are:

- Perform data profiling and quality assessment.
- Validate business keys and table relationships.
- Design dimensional data models using star schema principles.
- Build analytical SQL queries to answer business questions.
- Develop KPI-driven Power BI dashboards.
- Generate actionable business insights from e-commerce and marketing data.
